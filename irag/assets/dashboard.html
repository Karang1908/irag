Three steps to a working memory

Your project is initialised but no summaries have been written yet, so there is nothing for an agent to read.

  1. 1
    Point irag at a summariser. Edit .irag/config.toml → [llm].command. Use a cheap model here — this is the scribe, not your coding agent.
  2. 2
    Build the memory. One call per file and folder, once. After this, reading is free SQL forever.
  3. 3
    Make it automatic. Claude Code hooks inject memory at session start and update it after every turn, so you never think about it again.
